🎯 Objetivo

Integrar tecnologias de Inteligência Artificial generativa com frameworks open-source de videoconferência para criar uma solução Android funcional, moderna e escalável.

🚀 Funcionalidades
Criação e entrada em salas de videoconferência
Integração com Jitsi Meet SDK
Interface Android otimizada
Estrutura de código assistida pela Manus AI
Compartilhamento simples de salas
Compatibilidade com dispositivos Android
💡 Diferencial do Projeto

O diferencial do aplicativo está no contexto de uso da videoconferência, trazendo soluções voltadas para necessidades específicas, como:

Telemedicina
Educação online
Mentorias
Suporte remoto
Reuniões colaborativas
Atendimento especializado
🛠️ Tecnologias Utilizadas
Android Studio
Kotlin / Java
Jitsi Meet SDK
Manus AI
Gradle
XML para interfaces Android
